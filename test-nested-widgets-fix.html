Enhanced Radio Widget - Nested Widgets Fix

✅ Nested Widget Support Fixed! Enhanced radio widget can now properly handle embedded widgets.

🔧 What Was Fixed:

1. ✅ Added apiOptions to Renderer

The Renderer component now receives apiOptions which is required for proper widget initialization.

// Before: <Renderer content={content} widgets={widgets} findExternalWidgets={this.props.findWidgets} /> // After: <Renderer content={content} widgets={widgets} apiOptions={this.props.apiOptions} // ← Added this findExternalWidgets={this.props.findWidgets} />

2. ✅ Added traverseChildWidgets Function

This function allows Perseus to discover and manage nested widgets properly.

traverseChildWidgets: function(props, traverseRenderer) { return _.extend({}, props, { choices: _.map(props.choices, (choice) => { return _.extend({}, choice, { content: traverseRenderer(choice.content, choice.widgets, choice.images), }); }), }); }

3. ✅ Why This Was Needed:

  • apiOptions: Required for widget editors to function properly
  • traverseChildWidgets: Allows Perseus to find and manage nested widgets
  • Widget Discovery: Enables proper serialization and state management
  • Editor Integration: Allows widgets to be added/edited within choices
